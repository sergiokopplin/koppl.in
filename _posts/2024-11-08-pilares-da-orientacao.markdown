# Pilares da Orientação a Objetos

## Encapsulamento

Consiste em restringir o acesso direto aos dados de um objeto, permitindo o acesso apenas por meio de métodos específicos. Isso protege a integridade dos dados e permite que as alterações internas sejam feitas sem impactar o código que usa o objeto.

## Herança

Permite que uma classe (subclasse) herde atributos e métodos de outra classe (superclasse), promovendo o reuso de código e criando uma hierarquia de classes. Com a herança, é possível especializar comportamentos e características de uma classe para outras classes.

## Abstração

Refere-se à capacidade de ocultar os detalhes complexos de uma implementação e mostrar apenas as funcionalidades essenciais. Em orientação a objetos, abstração permite que se foque no "o que" um objeto faz, em vez de "como" ele faz.

## Polimorfismo

Permite que objetos de diferentes classes sejam tratados de forma intercambiável, contanto que compartilhem uma interface ou classe base comum. Em outras palavras, métodos podem agir de maneira diferente dependendo do objeto que os executa, possibilitando o uso de uma mesma função ou método com diferentes tipos de dados.
