# Classes

## Classe

Um exemplo de classe e seu diagrama. 
Essa classe tem abributos e controladores de acesso, ambos privados, públicos e protegidos.

Essas definições podem variar de linguagem para linguagem.

O identificador "-" indica que esse atributo ou método é privado e somente acessado internamente na classe.

O identificador "+" indica que esse atributo ou método é público e pode ser acessado internamente e externamente a classe.

O diagrama também contêm o retorno dos métodos, indicados depois do ":".

```js
class NomeClasse {
    private string atributoA;
    public number atributoB;

    private function metodo1(): string {
        // corpo do método
    }
    
    protected function metodo2(): number {
        // corpo do método
    }

    public function metodo3(): void {
        // corpo do método
    }
}
```

        + number atributoB

        - metodo2 () number
        + metodo3 () void

{% endmermaid %}

## Objeto

Um objeto é o resultado do processo de instanciação de uma classe.

Portanto, como no exemplo abaixo, alterações feitas no objeto1 não interferem no objeto2, pois eles são instâncias diferentes de objeto.

Exemplo:

```js
objeto1 = new NomeClasse();
objeto1.metodo3(); // público
objeto1.metodo2(); // gera um erro por ser privado ou protegido

objeto2 = new NomeClasse();
objeto2.metodo3(); // público
```

## Métodos de Classe (Estáticos)

Observe o exemplo a seguir:

```js
class NomeClasse {
    private string atributoA;
    public number atributoB;

    private function metodo1(): string {
        // corpo do método
    }
    
    protected function metodo2(): number {
        // corpo do método
    }

    public static function metodo3(): void {
        // corpo do método
    }
}
```

{% mermaid %}
classDiagram
    class NomeClasse {
        - string atributoA
        + number atributoB

        - metodo1 () string
        - metodo2 () number
        + metodo3 () void
    }
{% endmermaid %}

Métodos estáticos podem ser invocados sem que exista uma instância da classe, sem que exista uma referência de objeto criada.

```js
objeto1 = new NomeClasse();
objeto1.metodo3(); // público
objeto1.metodo2(); // gera um erro por ser privado ou protegido

NomeClasse.metodo3(); // estático
```

## Classe Abstrata

Uma classe Abstrata não pode ser instanciada e não gera objetos.
O nome no diagrama de classes fica em itálico para diferenciação, porém no nosso visualizador isso não funciona corretamente, por isso adicionei uma palavra para identificação.
Ela é declarada usando a palavra abstract.

```js
abstract class NomeClasse {
    private string atributoA;
    public number atributoB;

    private function metodo1(): string {
        // corpo do método
    }
    
    protected function metodo2(): number {
        // corpo do método
    }

    public function metodo3(): void {
        // corpo do método
    }
}
```

{% mermaid %}
classDiagram
    class abstractNomeClasse {
        - string atributoA
        + number atributoB
        - metodo1 () string
        - metodo2 () number
        + metodo3 () void
    }
{% endmermaid %}

Além das classes, podemos também ter métodos abstratos.

```js
abstract class NomeClasse {
    private string atributoA;
    public number atributoB;

    private function metodo1(): string {
        // corpo do método
    }
    
    abstract protected function metodo2(): number;

    abstract public function metodo3(): void;
}
```

Alguma subclasse deverá implementar os métodos abstratos para um futuro uso.
O método abstrato, portanto, não é implementado por só conter sua assinatura e retorno.
No diagrama de classe esses métodos aparecerão também em itálico (somente com a palavra no nosso exemplo).
Uma classe abstrata também pode fornecer reaproveitamento de código, onde a classe utilizadora pode reutilizar seus métodos.

        - string atributoA
        + number atributoB
        - metodo1 () string
        - abstract metodo2 () number
        + abstract metodo3 () void
    }
{% endmermaid %}

## Interface

Uma interface não pode ser instanciada e não gera objetos.
Ela é declarada usando a palavra interface.
Diferente da classe abstrata, a interface cria um protocolo a ser seguido, e a classe que a irá instanciar é obrigada e declarar todas as propriedades e métodos com suas assinaturas.

```js
interface NomeClasse {
    private string atributoA;
    public number atributoB;

    private function metodo1(): string;
    
    protected function metodo2(): number;

    public function metodo3(): void;
}
```
